# Support

Metadatapp is community-available public-preview software. Maintainers will do their best to respond, but no response time is guaranteed.

## Where To Ask

- Bugs: open a GitHub issue with reproduction steps.
- Feature ideas: open a GitHub feature request.
- Security issues: follow [SECURITY.md](SECURITY.md), not public issues.
- Setup questions: open a discussion if GitHub Discussions are enabled; otherwise open a question issue.

## What To Include

- repository revision or release tag
- operating system
- Docker and Docker Compose versions
- command that failed
- relevant logs with secrets redacted

## Commercial or Private Support

No public commercial support program is defined yet.
