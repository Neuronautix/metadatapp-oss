# SoftMouse

> SoftMouse is a colony-management system. Connecting it imports your mouse colony into Metadatapp.

## At a glance

| | |
| --- | --- |
| Integration code | `softmouse` |
| Direction | Import (external → Metadatapp) |
| External URL | your SoftMouse instance URL (placeholder `https://your-softmouse.example`) |

## Credentials you'll need

Username (required)
: Your SoftMouse account username.

Password (required)
: Your SoftMouse account password.

## Where to get them

Use the same username and password you use to sign in to SoftMouse. A dedicated service account is recommended over a personal login.

## Connect it

Follow the [standard connection steps](index.md#how-to-connect-any-app): open
**Connected Apps → App Directory → SoftMouse → Edit Settings**, enter the external
URL and the credentials above, **Test connection**, then save and trigger a sync.

```{note}
Credentials are stored server-side and shown afterward only as a masked hint.
Leave a field blank when editing to keep its current value.
```

## What gets synced

- Cages
- Subjects (animals)
- Studies
