# protocols.io

> protocols.io is a repository of research protocols.

## At a glance

| | |
| --- | --- |
| Integration code | `protocolio` |
| Direction | Import (preview) |
| External URL | `https://www.protocols.io` (leave blank to use the public API) |

## Credentials you'll need

Access Token (required)
: A protocols.io access token.

## Where to get them

Generate a token from your protocols.io developer/account settings.

## Connect it

Follow the [standard connection steps](index.md#how-to-connect-any-app): open
**Connected Apps → App Directory → protocols.io → Edit Settings**, enter the external
URL and the credentials above, **Test connection**, then save and trigger a sync.

```{note}
Credentials are stored server-side and shown afterward only as a masked hint.
Leave a field blank when editing to keep its current value.
```

## What gets synced

_Nothing is imported yet in the current preview (see notes below)._

## Notes

- This integration is in **preview**: the connection test is wired and validates your token, but automatic record import is not yet available.
