# Metadata models & forms

Metadatapp structures experimental metadata using a small set of building blocks:
**Common Data Elements (CDEs)**, reusable **Canonical Forms**, the **ISA**
experimental hierarchy, and **ontology** mappings. This section documents concrete
forms built on that pattern.

For the underlying concepts, see [Key concepts](../introduction/concepts.md). For a
related example of mapping external templates onto CDEs, see the Template
Crosswalk Studio documentation (`docs/template-crosswalk-studio.md`).
