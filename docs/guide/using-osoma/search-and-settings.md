# Search & personal settings

## Global search

Press `Cmd + K` (macOS) or `Ctrl + K` (Windows/Linux), or use the search box in the
top bar, to search across the platform from anywhere.

Results are grouped by type and cover your core records (Investigations, Studies,
Samples, Subjects, Assays, Datasets), facility/operations data, Zefix records
(lines, batches, systems), administrative resources (Users, Organizations, Audit
Log), and even settings pages (Profile, Appearance, API Keys, AI Providers,
Connected Apps). Admin-only results only appear for administrators. Select a result
to jump straight to it.

## Profile

**Settings → Profile** (`/settings/profile`) shows your account identity (name,
email, organization, organization role, subject ID — read-only from your sign-in)
and lets you edit a few personal fields such as a short bio and links.

## Appearance

**Settings → Appearance** (`/settings/appearance`) is a theming studio:

- **Theme presets** — e.g. Scientific, Live-Ops, Executive, Dark-Lab.
- **Fonts** — choose from a curated set.
- **Colors** — adjust primary/secondary/accent and status colors.
- **Data-visualization tuning** — grid visibility, axis contrast, curve smoothness,
  marker size, animation intensity.
- **Light/dark toggle** — also available directly in the top bar.
- **Undo / reset**, and **export/import** of theme tokens.
