# Evolution Reports

This folder contains one report per merged PR.

## Index

See `doc/evolution/INDEX.md` for the full list of generated reports.

## Quick checklist

Before closing a merge cycle, confirm the report includes:

- Clear summary of what was merged
- Concrete description of what this change enables
- Explicit benefits (user, product, developer, or operational)
- Long-term vision alignment
- Follow-up work and known limitations

## File naming

`YYYY-MM-DD-pr-<number>-<short-slug>.md`
