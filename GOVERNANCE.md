# Governance

Metadatapp is maintained by Neuronautix in the Neuronautix GitHub organization.

## Project Intent

The project is published so the community can inspect, run, preserve, and extend the platform. It is not yet governed as a foundation project.

## Maintainer Responsibilities

Maintainers are responsible for:

- reviewing and merging pull requests
- triaging issues
- keeping CI and setup instructions working
- prioritizing security fixes
- deciding release scope and timing

## Decision Making

Routine changes are accepted by maintainer review. Larger changes should start with an issue or design discussion before implementation.

Examples of larger changes:

- licensing or governance changes
- database model changes with migration impact
- authentication or tenant-boundary changes
- public API changes consumed by Osoma or integrations
- new external Connected Apps

## Contributor Path

There is no formal maintainer nomination process yet. Sustained, high-quality contributions may lead to expanded repository permissions by maintainer decision.
