# Roadmap

Metadatapp is in public preview. This roadmap is intentionally conservative and focuses on making the project easier to run, review, and extend.

## Near Term

- Complete open-source readiness checks.
- Sanitize environment defaults, reports, and sample data.
- Improve clean-clone setup documentation.
- Keep public CI fork-safe.
- Document the Connected Apps extension model.
- Add public-safe screenshots or demo media.

## Medium Term

- Harden tenant isolation and security review coverage.
- Improve API/Osoma contract tests.
- Expand fixture and mock integration data.
- Stabilize AI-assisted curation workflows.
- Improve deployment documentation for self-hosters.

## Long Term

- Define a formal maintainer path.
- Publish versioned releases.
- Expand community documentation.
- Evaluate plugin boundaries for external integrations.
