# Metadatapp Connected Apps Showcase Content

## Headline

Metadatapp connects the research stack into one FAIR metadata graph.

## Subheadline

Protocols, colony data, repositories, live sensors, home-cage analytics, and FAIR publication workflows communicate through Metadatapp instead of staying in separate tools.

## Core Message

Metadatapp sits between the tools research teams already use: electronic lab notebooks, colony management systems, protocol registries, open-science repositories, ontology services, metadata template systems, live sensors, and home-cage analytics platforms.

Instead of asking scientists to copy information between systems, Metadatapp keeps source identifiers, provenance, and synchronization state attached to the research record. Osoma shows the operational view; the backend handles credentials, synchronization, validation, and publication boundaries.

## Value Props

- Backend-mediated integrations keep external credentials and device access away from the browser.
- External identifiers are preserved, so every imported record stays traceable to its source system.
- FAIR assessment, export, and publication workflows can use connected evidence as soon as it lands in Metadatapp.

## Connected Apps

| App | Role | Flow | What Metadatapp Uses |
| --- | --- | --- | --- |
| eLabFTW | Electronic lab notebook | Bidirectional | Studies, experiments, protocols, notebook links |
| SoftMouse | Mouse colony management | Inbound | Subjects, cages, studies, weight measurements |
| FAIR3R | FAIR data repository | Outbound | Investigations, studies, FAIR datasets |
| OSF | Open science repository | Inbound | Studies, repository links, datasets |
| PreclinicalTrials.eu | Preclinical study registry | Inbound | Investigations, study protocols, registry links |
| Tecniplast DVC | Home-cage monitoring and DVC analytics | Bidirectional | Cages, subjects, variables, time series, circadian metadata |
| Sovereign Sensor Agent | Live environmental sensor proxy | Proxy | Sensor readings, alarms, environmental observations |
| protocols.io | Protocol repository | Validation | Protocols and external provenance links |
| CEDAR | Metadata templates | Validation | Metadata templates and structured forms |
| BioPortal | Ontology lookup | Validation | Ontology terms, semantic annotations, variables |

## Short Website Copy

Metadatapp does not replace specialized research tools. It connects them.

An eLabFTW protocol can become a structured study. SoftMouse colony data can follow animals into experiments. Tecniplast DVC activity can become reusable time-series evidence. FAIR3R and OSF can receive publication-ready metadata. CEDAR and BioPortal prepare the workflow for template-guided, semantically enriched capture.

The result is a live metadata graph where research operations, FAIR quality, and publication readiness stay connected.
